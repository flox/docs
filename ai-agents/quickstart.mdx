Paste one prompt into the AI agent you already use, and it turns your skills, plugins, and sandbox into an agent stack: an environment that starts the same agents, with the same plugins, here and on your other computers.
It installs Flox and Agent Stacks first if they are missing.

## What you need

- A Mac with Apple silicon, or a Linux machine on `x86_64` or `aarch64`.
  Intel Macs are not supported, because `flox/flox-agent` is not built for them.
- A free FloxHub account.
  The onboarding helps you log in.
- An AI agent that can run shell commands on this machine, such as Claude Code or Codex.

## Run the prompt

Paste this prompt into your agent:

```text
Install Flox and Agent Stacks if they are missing, then turn my current agent setup into an agent stack.
Save the flox skill to a new temporary folder with
curl -fsSL -o <folder>/SKILL.md https://raw.githubusercontent.com/flox/flox-skills/main/flox-plugin/skills/flox/SKILL.md
then read that file whole with your file tool, not a summary of it.
Follow its "Installing Agent Stacks" section, then the reference it sends you to, from start to finish.
```

Answer the agent's questions as they come.
The first build takes a few minutes, and the agent ends with how to start your stack.
If you choose your other computers too, it waits for the upload to FloxHub before it ends, which takes a few minutes more.

To read what the prompt does before you run it, open [the `flox` skill](https://github.com/flox/flox-skills/blob/main/flox-plugin/skills/flox/SKILL.md) and its [Agent Stacks reference](https://github.com/flox/flox-skills/blob/main/flox-plugin/skills/flox/references/agent-stacks.md).
